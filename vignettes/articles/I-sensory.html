Vocabulary harmonization & panelist scaling

harmonize_terms() orders dictionary patterns by decreasing length and applies two-pass sentinel token replacement (\x01<idx>\x02) so shorter patterns never overwrite substrings inside already-translated terms:

data(dictionary_generic)
harmonize_terms(
  dictionary = dictionary_generic,
  x = c("amer", "acidulé", "métallique"),
  mode = "word"
)
#> [1] "BITTER"     "ACIDULÉ"    "MÉTALLIQUE"

load_consistent_profiles() retains taste descriptors used by at least min_jury distinct panelists and optionally applies multiplicative root-mean-square (RMS) scaling per juror (normalize_panelists = TRUE):

data(profiles)
consistent_raw <- load_consistent_profiles(
  profiles,
  min_jury = 2L,
  normalize_panelists = FALSE
)
consistent_rms <- load_consistent_profiles(
  profiles,
  min_jury = 2L,
  normalize_panelists = TRUE
)
head(unique(consistent_rms[, c("taste", "sum_taste", "group")]), 10)

3-AFC concentration-response & psychometric threshold

plot_concentration() fits a guessing-corrected 3-AFC binomial psychometric curve (\(P(c) = 1/3 + (2/3)\Lambda(\beta(\log_{10} c - \mu))\)) with 95% delta-method confidence ribbons and marks the 50% true detection threshold (\(\text{EC}_{50}\) at \(P = 2/3\)):

out_conc <- tempfile(fileext = ".pdf")
plot_concentration(output = out_conc, afc_m = 3L)
#> [1] "/tmp/RtmpHJOQOO/file1d807850358b.pdf"

Chasselas taste modulation (Pratt signed-rank test)

plot_chasselas_modulation() evaluates paired before/after wine taste ratings around median zero using Pratt’s (1959) zero-preserving Wilcoxon signed-rank test (test_method = "pratt"), retaining zero differences during ranking with exact zero- and tie-variance corrections:

out_mod <- tempfile(fileext = ".pdf")
plot_chasselas_modulation(output = out_mod, test_method = "pratt")
#> [1] "/tmp/RtmpHJOQOO/file1d8053b26bdf.pdf"
