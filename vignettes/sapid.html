General comments about the use of SAPID

Author

Adriano Rutz

Published

November 10, 2026

This vignette outlines the workflow and statistical methods implemented in sapid (Strategy to Analyze Plant Extracts Taste In Depth).

Installation

install.packages(
  "sapid",
  repos = c(
    "https://adafede.r-universe.dev",
    "https://taxonomicallyinformedannotation.r-universe.dev",
    "https://cran.r-universe.dev",
    "https://bioc.r-universe.dev"
  )
)

Workflow overview

  1. Vocabulary harmonization & panel scaling:
    • harmonize_terms() and harmonize_terms_df() standardize free-text French panelist terms using length-ordered two-pass sentinel token replacement (\x01<idx>\x02) so shorter patterns never overwrite already-translated substrings.
    • prepare_profiles() corrects FIZZ > 10 scale export artifacts prior to deduplication and aggregates synonymous ratings per panelist and sample via max(value, na.rm = TRUE).
    • load_consistent_profiles() retains descriptors used by at least min_jury distinct panelists and optionally applies multiplicative root-mean-square (RMS) juror scaling (normalize_panelists = TRUE).
  2. Psychophysics & sensory evaluation:
    • plot_concentration() fits a guessing-corrected 3-AFC binomial log-logistic psychometric model (\(P(c) = \gamma + (1 - \gamma)\Lambda(\beta(\log_{10} c - \mu))\) with \(\gamma = 1/3\)) to estimate the 50% true detection threshold (\(\text{EC}_{50}\) at \(P = 2/3\)) and delta-method 95% confidence ribbons.
    • plot_chasselas_modulation() evaluates paired before/after wine modulation using Pratt’s (1959) zero-preserving Wilcoxon signed-rank test (test_method = "pratt").
    • plot_informed_tasting() compares classical raw-extract tasting against gravimetrically reconstituted fraction tasting using harmonized panelist-normalized intensities.
    • plot_napping() performs Procrustes MFA (SensoMineR::pmfa()), MFA with descriptor word contingencies as a supplementary block (FactoMineR::MFA()), and Ward’s hierarchical clustering (FactoMineR::HCPC(method = "ward")).
    • plot_descriptors_network() builds a simple weighted directed graph of sample fractions, original panelist terms, and harmonized descriptors.
  3. 1D proton NMR & LC-MS/CAD correlation:
    • cluster_nmr() excludes solvent regions prior to total-area normalization, merges detected peak positions within peak_width_ppm / 2, and clusters fractions using Hellinger distance (dist_method = "euclidean" on square-root areas) with ward.D2 linkage.
    • correlate_ion_taste_intensities() and plot_correlations() compute rolling-window correlations across contiguous fractions, map Kendall’s \(\tau\) onto the Pearson-equivalent scale via Greiner’s relation \(r_{\text{eq}} = \sin(\frac{\pi}{2}\tau)\), deduplicate co-eluting 2D InChIKeys within local retention-time windows (rt_window = 0.5 min) to preserve chromatographic isomers, and rank candidates via a sample-size-adjusted Fisher-\(z\) desirability score.
